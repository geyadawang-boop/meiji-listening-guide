# 更新日志

## Unreleased

- 媒体工具解析支持白名单系统回退：未打包开发环境在缺少应用内组件时使用系统 FFmpeg/FFprobe（macOS `/opt/homebrew/bin`、`/usr/local/bin`；Linux `/usr/bin`、`/usr/local/bin`），打包应用需显式 `MEIJI_SYSTEM_MEDIA=1`；不搜索 PATH，仍校验真实路径与执行权限。
- 运行清单与打包过滤按平台化：清单按 `process.platform` 收录 `ffmpeg`/`ffprobe`（Windows 为 `.exe`），portable 只按组件目录是否存在取舍，缺少组件目录时清单生成跳过并告警，`release-info.json` 记录实际跳过项。
- 运行环境安装入口与会话助手提示改读 `app:info` 的 `platform`（不再使用已废弃的 `navigator.platform`）；登录档案文案改为「当前系统用户加密保存」。
- macOS 关闭全部窗口保留应用在 Dock，重新激活时恢复主窗口；Windows/Linux 保持关闭即退出。

- 组件服务可只读识别 v2 清单并检查目标、完整性与权限，界面显示缺失或校验失败原因；v2 安装仍在写入前拒绝，旧清单保持原有状态含义。

- 增加仅用于隔离临时目录的 v2 视频安装验证实验及手动 Mac 权限检查，不接正式安装器，不执行组件。

- 增加独立 macOS arm64 视频候选清单与 descriptor v2 生成工具，逐项绑定工具和来源资料摘要；仅生成待审工件，不执行或安装组件。

- 新增独立运行组件 v2 清单契约，校验显式平台目标、文件配对、路径、摘要、大小与权限；尚未接入安装或发布，旧 Windows 清单行为不变。

- 增加手动 macOS arm64 源码构建候选与应用编码器矩阵检查，拒绝 nonfree 配置和非系统动态依赖；工件仅供审查，不安装或发布。

- 增加七份固定媒体源码的下载与安全解包检查，保留来源、摘要和许可定位；手动 macOS CI 仅准备源码，不编译、安装或发布。

- 设置布局使用通用命名，清理无引用旧品牌样式和图标；文档同步系统密钥库验证范围与历史第三方资源说明，保留原许可记录和旧配置兼容。
- 手动 CI 可显式选择隔离运行锁定的 macOS arm64/Linux x64 FFmpeg 候选，记录实际版本、依赖与签名状态并检查转码和工作进程取消；不安装、发布或上传二进制。

- 增加固定来源的媒体组件离线暂存工具，仅校验本地候选文件的大小、摘要和目标架构；不下载、执行或接入安装，许可、对应源码与目标平台运行仍待验证。
- 增加仅手动触发的三平台运行验证，使用隔离合成资料检查系统密钥库、工作进程恢复与设置导航，不安装或发布产品。

- 内置提示词源文件归入 `src/prompts`，开发读取、安装包资源与源码包路径同步；提示词内容保持不变。
- 空组件文件清单不再误报已安装，安装时会在创建目录前拒绝空清单。
- 媒体工具按系统解析 FFmpeg/FFprobe 文件名，并在运行前校验资源路径、文件类型及执行权限；保持 Windows 路径，不自动下载其他平台组件。

- 主进程 IPC 与预加载脚本使用统一共享模块别名，保持开发及生产构建的引用一致。
- 通讯助手提前禁用非 Windows x64 的本机微信与内置 QQ 后台操作并说明原因；手工 QQ、Web/iLink 保留，旧账号可从“已保存会话”查看本地消息。

- macOS/Linux 的 portable 构建不再随包复制 Windows 专属可选组件，即使本地已有这些资源；Windows portable 保持原行为；当前 Windows 组件包拒绝以 macOS/Linux 为目标生成。
- 通讯凭据与会话通过主进程系统密钥库加密，保留 Windows 原格式；等待加密期间若连接或登录状态改变，会保留原记录并拒绝过期写入。

- 媒体工作进程通过主进程系统密钥库保存 Cookie 和私密任务记录，保留 Windows DPAPI 格式；加密通道失败时拒绝落盘。
- 模型与搜索密钥拒绝使用不可用或不安全的系统密钥库；保留旧密钥时先验证可读性，避免保存其他设置后才报告密钥错误。
- 修复设置子页切换时退为弹窗的问题：通义千问、搜索与主题、提示词保持同一整页布局和导航位置。

- 新增课程学习证据包导出：字幕页提供 Markdown 入口，笔记页提供 JSON 和 Markdown 入口，包含字幕、笔记、课件和练习来源。
- 模型设置改为千问 API，分别选择文本与视觉模型；移除 ChatGPT/Codex 账号和 DeepSeek 专用入口，旧凭据不会自动转给千问。
- 课件校订保留已有 OCR 与人工文本并说明提取限制；画面识别成果可从已保存结果恢复，避免覆盖用户编辑。
- 三平台安装包使用独立 SHA256 校验清单，发布流程明确目标仓库。
- 非 Windows 平台禁用 Windows 运行组件安装，并显示原因。

- 源码包包含 Git 忽略规则、CI 与发布工作流、更新日志和现有跨平台适配清单。
- 安装项目依赖时先检查并准备 Electron 二进制，再重建原生依赖。
