# 课程学习证据包导出（开发分支）

本变更基于 `0.1.85` 源码，尚未发布新版本。用户在课次的「听课笔记」页可导出 JSON 或 Markdown 证据包。即使尚无笔记，也可以导出已有资料和各项缺失状态。原有字幕、笔记、练习导出入口保持不变。

## 文件与格式

- `src/shared/course-evidence.ts`：纯数据构建器与 Markdown 渲染；不访问课程数据库、媒体文件或外部服务。
- `src/main/exports.ts`：复用文件预留和失败清理机制，新增 `evidence-bundle` 的 `json`、`md` 格式。
- `src/main/ipc/desktop.ts`：将新类型加入 `export` 操作白名单，并在创建输出目录及预留文件前校验类型与格式。
- `src/renderer/src/App.tsx`：笔记页增加两个导出按钮。
- `package-lock.json`：在恢复依赖时用当前 manifest 同步锁文件，保留所有既有包版本、未删除记录，补入 130 个跨平台可选依赖/元数据条目；该文件变化用于让锁文件与项目 manifest 同步，不包含应用功能代码。

JSON 合同为 `schemaVersion: "1.0.0"`，含 `producer`（应用名和实际运行版本）、`generatedAt`、`revisionId`、课程/课次元信息、`coverage`、`sources`、`evidence`。`evidence` 下有字幕、笔记、摘要要点、课件提取文本/页标记/笔记中的课件引用、画面、知识库引用和练习。练习分历年题、来源拓展题及 AI 自测题，保留题干、来源、参考答案、解析和已保存的个人作答/应用判定。Markdown 呈现同一批内容和缺失说明；字段名以 JSON 为准。

`revisionId` 是按当前课程/课次内容、来源文件名、文本与记录哈希、校订覆盖计算的 SHA-256 快照指纹，不是数据库中已有的来源 revision，也不是文件原字节校验。`contentHash` 对相应已保存的文本或 JSON 记录计算 SHA-256；缺失数据不写入内容哈希。`startMs`/`endMs` 为毫秒。课次关联的原文、课件和视频来源只输出文件名，不输出本机绝对路径；已有练习记录中的 `sourceFile` 按原值保留，旧记录若含路径会照常导出。原始语音识别文本、课件提取文本、字幕、练习及学习作答会进入用户主动导出的文件，分享前应自行检查。

## 状态含义

- `verified`：限于应用中明确保存的校订/原话时间匹配结果。例如完整字幕中的片段同时有原文对照且 `uncertain === false`，或笔记原话匹配标记为 `verified: true`。这不代表教师、原始音频或外部权威已独立证实模型内容。
- `uncertain`：存在内容，但来源校订标记、原文对照或独立核对不足；含糊表态即使原句能匹配，也保持此状态。练习、参考答案和课件提取文本亦属此类。
- `unavailable`：当前课次未保存对应资料或没有可关联的记录；不以空数组冒充已核验结果。

字幕若处于断点校订，`coverage.partial` 和 `completed/total` 明示进度，所有该快照片段保持 `uncertain`。从外部直接导入的 SRT 没有逐句校订标记，也保持 `uncertain`。笔记分别保留教师明确重点、明确不考和表态含糊三个类别；摘要要点仅复用已保存的教师明确重点，不另行生成泛化视频总结。练习题来源和 AI 生成标记来自现有题目记录，导出器不验证网页或参考答案的真实性。

## 当前边界与回退

现有课次表没有与每节课持久关联的画面帧、OCR 结果或知识库引用。因此这些区块明确为 `unavailable`，也不生成置信度。课件可能有文件记录却没有可导出的提取文本；此时保留来源文件名，课件证据仍为 `unavailable`。本变更不修改数据库 schema，不拼接其他产品数据库，不自动导入知识库，也不读取原媒体重新处理。

本地 builder、构建和隔离 UI/IPC 导出已按本任务测试记录检查。真实外部 ASR、OCR、模型服务、知识库同步及外部来源事实未在本轮验收；原十二来源能力账本和旧待办/确认状态不变。本次未发版，也未安装到真实用户目录。`npm run audit:typescript` 仍受仓库现有脚本的副本目录和迁移清单路径依赖阻塞，未为通过该脚本而创建伪副本或构建安装包。

回退可撤销本分支的代码与界面改动；数据库无需迁移或回滚。已导出的 JSON/Markdown 是普通文件，可按用户意愿自行保留或删除。此变更未推送、合并、安装或生成应用包。
