# 课件读取、图片预算与画面成果恢复

本次修复了 PPTX ZIP 展开上限、校订图片预算披露、笔记课件限制保留和画面识别成果写入恢复。

- `src/main/documents.ts`：读取 PPTX 页面目录、页面关系、页面 XML 和媒体前先检查 ZIP 展开大小，再通过有界流逐块计量实际字节。流长度超过声明大小或本地上限时停止 JSZip worker 链，拒绝将展开结果积存在内存中。图片总预算耗尽或单张超过上限时不读取该图片，并记录页码和省略原因。
- `src/main/workflows.ts`：字幕校订请求将图片大小筛选原因连同页码发送给模型并在进度报告中显示。生成笔记时先从课件文本末尾独立解析 `[课件提取限制]`，再截取最多 12,000 字的课件文字；超过上限和扫描 PDF 未 OCR 的原因都会进入模型限制参数及进度。
- `src/main/visual.ts`：部分识别结果先写入唯一临时文件并校验 SHA-256，然后持久化恢复记录，再替换成果文件并保存任务哈希。中断后可按恢复记录完成替换或登记已替换的成果；若成果文件已被用户编辑，则保留原文件并中止覆盖。
- `README.md`：移除过时的 Codex 打包组件说明，保留第三方许可与署名文件引用。

验证结果在完成本地 typecheck 和隔离回归后补录。验证仅使用合成课件、临时目录和假识别器，不调用真实云服务、不读取用户课程资料，也不安装应用。
