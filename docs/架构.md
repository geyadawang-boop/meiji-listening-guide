# 架构与模块边界

React 页面通过隔离 preload 桥访问主进程业务接口。主进程持有账号与模型连接，知识库、媒体下载、研究和本机微信读取在独立 TypeScript 工作进程内运行，通过有限消息协议协作；不启动 Python、yt-dlp 或 BiliSum 网页服务器。

知识库使用 knowledge-native.sqlite、中文全文与本地 BGE ONNX。研究直接绑定知识库来源代际和正文哈希；旧 JSON/SQLite 只读建立基线。旧工作流只展示历史结果，继续分析必须绑定当前来源。

媒体下载使用各平台原生目录、ETag/范围/哈希断点及原生并行传输，FFmpeg 只处理本任务下载到本地的文件，守护进程负责取消和退出。结果时长、画面、音轨、字幕和哈希通过后，才清理任务中间文件。

登录档案由 media-auth.ts 管理，DPAPI 密文不会导出为 Cookie 临时文件；下载元数据及媒体请求分别按目标域匹配。选用加密任务记录时由 media-jobs.ts 保存 job.dpapi，恢复与成果核验仍走同一队列。

ASR 使用独立 TypeScript 进程和本地 Whisper/Silero ONNX。PDF 增量批注、二维码、来源和导出均在原生应用逻辑内完成。FFmpeg、SQLite、ONNX、QuickJS WASM、Electron 与模型连接 CLI 是独立第三方组件。

主窗口禁用 nodeIntegration，开启 contextIsolation/sandbox，仅允许主框架调用已登记 IPC。每个业务接口通过明确类型依赖获取服务。UI 不导入 Node 或展示上游网页。

目录按业务域组织：主进程 `src/main` 下 `app`（组合根/窗口/生命周期）、`ipc`（动作白名单）、`workers`（工作进程入口）与 `media`、`knowledge`、`research`、`im`、`learning`、`documents` 等业务域；渲染层 `src/renderer/src` 下 `app`（壳与标题栏）、`features/<域>`、`ui`（跨域组件）、`lib`、`styles`、`assets`；`src/shared` 只放协议与纯函数。跨目录引用统一使用 `@main/*`、`@renderer/*`、`@shared/*` 别名，禁止跨目录相对路径。

前端使用 HeroUI v3（`@heroui/react` + `@heroui/styles`）与 Tailwind CSS 4，样式层顺序固定为 `legacy → theme → base → components → utilities`；交互控件使用 HeroUI React 组件，语义变量映射到现有调色板，图标使用 lucide-react。整页功能窗口共用 `ui/WindowPanel`（统一 280px 左菜单、窄屏 240px、内容区 32/40 间距与页头节奏），设置类界面集中在 `features/settings/SettingsHub`，入口固定在左侧栏底部的设置按钮。主窗口为自绘标题栏：Windows/Linux 使用 `frame: false`，macOS 使用 `hiddenInset` 保留红绿灯；最小化/最大化/关闭通过 `window:*` IPC 白名单执行，最大化状态经事件通道同步。

课程、知识库、研究、通讯和下载各自管理持久事务与取消；成果必须核验，模型未知结果不自动重试。关闭应用停止所属子进程，不强制结束用户的其它应用。历史实现保存在「历史参考」压缩归档，当前打包配置不读取该目录。
